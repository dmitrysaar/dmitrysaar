# Чек-листы

Здесь собраны ссылки на чек-листы, которые я составлял для разных проектов. 


## 🔍 Яндекс Поиск
[https://docs.google.com/spreadsheets/d/1f3ZL6maJSrgvHZBppe2uW2VYO_Bn1IdqrwEQipb_rfc/edit?gid=0#gid=0] В стандартный чек-лист были добавлены краткие шаги и ожидаемый результат. В ходе исследования была найдена "пасхалка", в которой при вводе пробелов в поисковую строку и дальнейшего нажатия на Enter открывается страница, которую разработчики не захотели убирать.
