# Отчёты о дефектах

Здесь отобраны образцы отчётов о дефектах, в основном на проект с интернет магазином. Представлены для удобства в виде скриншота. Практически каждый отчёт содержит в себе видео, для максимально легкого воспроизведения бага.

## 1. Регистрация : Пользователь не может зарегистрироваться с валидным логином без символа _ (нижнее подчеркивание)


## 2. Оформление заказа : Не приходит письмо на почту, после успешно оформленного заказа


## 3. Сортировка : Значение "По убыванию" показывает товары с ценой по возрастанию, значение "По возрастанию" показывает товары с ценой по убыванию. 


## 4. Добавление товара в корзину : Добавляется товар с граничным значением "0", негативным "-1" и пустым полем


## 5. API : POST /cart - Добавляется товар в корзину пользователя с quantity = 0 / -1 (аналогичный дефект с методом PATCH)
