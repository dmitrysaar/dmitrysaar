## 10. Пасхалка на яндекс поиске, или "Это не баг, а фича(?)". При вводе в поисковую строку значения, состоящего только из пробелов выполняется поиск и открывается страница [с пасхалкой](https://ya.ru/search/?text=+++&lr=213&search_source=yaru_desktop_common&search_domain=yaru)

Шаги для воспроизведения :
1. Открыть страницу https://ya.ru
2. Кликнуть левой кнопкой мышки на поисковую строку для активации ввода
3. Ввести значение только из пробелов (например нажать 3 раза на пробел)
4. Нажать Enter (или на кнопку "Найти" <img width="112" height="95" alt="image" src="https://github.com/user-attachments/assets/74a68d8a-0644-46f2-9779-679a025b8a3e" />)

Фактический результат : Поиск со значением из пробелов выполняется, открывается страница, содержащая сообщение "Вы задали пустой поисковый запрос и попали на эту страницу. Эта страница — продуктовый баг, её реально не должно быть. Просто руки не доходят убрать."
Ожидаемый результат : Пробелы обрезаются и поиск не выполняется, либо получено сообщение, что запрос не может быть пустым.
