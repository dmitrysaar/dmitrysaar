# Тест-кейсы

Здесь собраны ссылки на тест-кейсы, составленные на разных проектах. Изначально на практических задачах использовал QASE, после перешёл на TestIT, из-за более стабильной работы.

## 🛒 Интернет-Магазин (учебная площадка intern.demoshopping)
[Ссылка на тест-кейсы](https://docs.google.com/spreadsheets/d/1YpGpCS7qP0s2ZwjfYmPo964fkFILP-L_nEae9OtfwXk/edit?usp=sharing) Нашёл эту площадку максимально удобной для отработки навыков тестирования, т.к. есть (была на момент тестирования) связь с базой данных и API. Например, такие проверки, как оформить заказ можно сразу проверить и в БД, создался ли реальный заказ, или не продублировался ли он. Примеры SQL запросов так же присутствуют в шагах. 

Сам тест-кейс приведён в читабельный вид после экспорта из TestIT.
