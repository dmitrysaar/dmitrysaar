
# ⚽ Bet Manager

![CI](https://github.com/dmitrysaar/dmitrysaar/actions/workflows/ci.yml/badge.svg)

## 📖 О проекте

Это приложение для расчёта прибыли со ставок на футбол. Изначально идея была 
создать просто базу данных под ставки других прогнозистов на ЧМ 2026 и считать 
их результаты, отрабатывая при этом SQL-запросы. Но в дальнейшем, уже с базой 
данных, идея переросла в желание пройти полный SDLC с подключением 
тестирования на ранних этапах.

> **Моя роль:** QA-тестировщик (серый и чёрный ящик). Составил начальные 
> требования, продумал логику приложения с нуля.
> 
> **Важно:** код реализован с помощью ИИ-ассистента по моим требованиям.

В целом — это учебный pet-проект для отработки навыков тестирования 
и погружения в цикл разработки и тестирования.

### 🔮 Планы на будущее

В дальнейшем хотелось бы интегрировать приложение с внешними футбольными API -
чтобы подтягивались результаты матчей и лайв-статистика, а ставки рассчитывались 
автоматически после завершения события. В идеале - связать с API букмекерских 
контор, но это сложнее: у большинства БК закрытые API, требуется партнёрство 
и соблюдение юридических ограничений.

Пока эту часть решил оставить на потом - когда сам изучу Python и буду 
практиковаться на реальном проекте.

## Что умеет приложение :

- Ведёт небольшой учёт матчей, возможно, в дальнейшем можно будет реализовать функцию определения "любимой" команды, с которой получена бОльшая прибыль.
- Позволяет добавлять ставки на матчи для дальнейшего расчета результата с них (тип ставки, сумма ставки, коэффициент, результат)
- Фиксирует дальнейший результат ставки : Выигрыш, проигрыш, или возврат.
- Рассчитывает чистую прибыль по прогнозисту (беттору) за выбранный период времени.
- Важно! Т.к. приложение задумано, как учебное и не для релиза - в нём нет классического создания нового пользователя. Оно реализуется только через API.

## Логика расчёта прибыли :

Приложение считает именно чистый результат со ставки, а не сумму вместе с ставкой.
Например, беттор поставил 1000 рублей на коэффициент 1.85 и ставка выиграла. Его чистая прибыль со ставки составит 850 рублей. 1000 * (1.85 -1) = 850 рублей.
При проигрыше получаем результат прибыли в -1000.
При возврате получаем результат прибыли в 0 (ничего не выиграли, ничего не проиграли)

## Как запустить

### 1. Установить зависимости
```bash
pip install -r requirements.txt
```

### 2. Создать базу данных
```bash
sqlite3 bet_base.db < schema.sql
```
*(если `sqlite3` CLI не установлен — можно выполнить `schema.sql` через DB Browser for SQLite или DBeaver)*

### 3. Запустить сервер
```bash
python main.py
```

Приложение будет доступно по адресу: http://127.0.0.1:8000

### 4. Открыть фронтенд
Открыть файл `index.html` в браузере.
