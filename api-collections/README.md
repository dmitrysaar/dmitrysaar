# API коллекции

Здесь собраны коллекции API в Postman в двух вариантах : веб версия (через publish в postman) и json для большей подробности. 

В них содержится : Е2Е сценарии (полный путь пользователя), CRUD операции (каждый модуль - своя папка), позитивные / негативные проверки, pre-request скрипты для автоматического создания данных и подстановки переменных для дальнейших запросов, а так же post-request, где смотрим, что приходит в ответе и подсохраняем какие-либо полученные данные опять же, для дальнейших запросов.
