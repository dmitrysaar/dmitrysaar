## Подсчёт выигрыша/проигрыша со ставок на футбол прогнозистов (РБ/Ютуб)
[Ссылка](https://docs.google.com/spreadsheets/d/1sbub4RIh8XHIQbn4tbZ0Sl9_dv8AfQTEH6gFGDoPrWM/edit?gid=0#gid=0)
Это мой собственный проект, который хочу развить в полноценное приложение в будущем, при наличии необходимых навыков и знаний. Идея родилась моментально, когда хотел потренироваться с SQL, захотелось сделать что-то своё для практики. Краткая суть : заносим матчи, тип ставки, сумму ставки, прогнозиста и далее считаем, кто в итоге идёт в плюсе, кто в минусе. 

Имеем 3 таблицы :
matches — информация о матчах (дата, турнир, команды, результат)
bettor — прогнозисты (никнейм)
bets - ставки (тип, сумма, коэффициент, выигрыш/проигрыш)

Центральная таблица — bets. Она связывает matches и bettor через внешние ключи.
